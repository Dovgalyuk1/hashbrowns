# HASHBROWNS

Одностраничный лендинг мемкоина $HASHBROWNS — пиксельная картошка-майнер.

**Идея:** браузер честно считает SHA-256. Каждый хеш, который падает ниже таргета,
"жарится" в хеш-браун, и картинка драника рисуется процедурно из самого хеша —
форма, прожарка, количество соломки. Двух одинаковых не бывает. Восемь драников = полная тарелка.

## Структура
- `index.html` — весь сайт (HTML + CSS + JS, без сборки)
- `assets/` — вырезанный персонаж, кадр моргания, кропы, фон сцены, фавикон

## Настройка перед листингом
В начале `index.html`, блок SETTINGS:

```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку (пока пусто — кнопка неактивна)
```

## Что внутри
- Гейт CLICK TO ENTER (решает автоплей звука)
- Hero: персонаж, клик по нему сыплет монеты + звук, моргание подменой кадра
- THE FRYER — мини-игра: реальный SHA-256 в Web Worker, авто-подстройка сложности
  под скорость машины (цель ~4.5 с на драник), сковорода на canvas, тарелка из 8 слотов
- THE KITCHEN LOG — 8 карточек, открываются по мере намайненных драников
- FIELD NOTES, спек-лист, футер, финальная карточка + дождь монет
- Звук: шкворчание на Web Audio (фильтрованный шум), кухонная полька как фоновая музыка
